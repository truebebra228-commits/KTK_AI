# Оптимизация, 5 ноября 2026

Неподвижное окружение каждой комнаты рисуется один раз в текстуру 1280×720.
На следующих кадрах движок выводит эту текстуру и анимированные детали:
руки, бомбы, птиц, пыль, лампы, дверь и конфетти. Параметры бумажек и фактура
камня вычисляются заранее; текстура бомбы общая для всех зарядов.

Замеры выполнены Godot 4.7.2, OpenGL Compatibility, NVIDIA RTX 3050,
без VSync, по 250 настоящих кадров на комнату. Сравнивается один и тот же
сценарий с движением предпросмотра бомбы и взрывами. Это измерение конкретного
сценария на данном компьютере; оно не обещает одинаковую частоту кадров на других.

| Показатель | До | После |
| --- | ---: | ---: |
| Комната 1: CPU на подготовку отрисовки окружения | 3,780 мс | 0,390 мс |
| Комната 1: вызовы отрисовки за кадр | 952 | 193 |
| Комната 1: кадров/с в тесте | 75,9 | 268,5 |
| Финальная комната: CPU на подготовку отрисовки | 0,484 мс | 0,156 мс |
| Финальная комната: кадров/с в тесте | 279,2 | 296,1 |

Текстура комнаты занимает около 3,52 МиБ видеопамяти и освобождается при
смене комнаты. Размер персонажа, графика и частота физики 120 Гц сохранены.
Руки считают две пружинные цепочки примерно за 7 мкс на шаг.

Повторить измерение: запустить `tests/performance_probe.gd` с графикой, без
`--headless` и без `--fixed-fps`. Исходный вариант сохранён в тестовой копии
`tests/performance_baseline_level.gd`; эти файлы исключены из игровых сборок.

Для загрузки на GitHub подготовлена web-версия: официальный WebAssembly-
движок сжимается gzip без потерь и распаковывается браузером. Редактируемые
исходники Godot располагаются отдельно в `project/` внутри GitHub-пакета;
Windows EXE, кэши импорта и снимки тестов туда не включаются.
