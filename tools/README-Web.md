# Компактная web-сборка

Нужны Python 3 и обычный Godot 4.7.2 (не .NET). Из корня проекта:

```powershell
python tools/fetch_web_template.py --output web_nothreads_release.zip
python tools/build_github_web.py --godot 'C:/path/to/Godot.exe' --template web_nothreads_release.zip --output ../github
```

Шаблон скачивается из официального выпуска Godot по диапазонам HTTP: около
10 МБ вместо всего архива экспортных шаблонов на 1,28 ГБ. Проверяется ZIP CRC.

Сборщик создаёт временную копию проекта, импортирует её и экспортирует Web без
потоков. Он не меняет игровой код, графику и основной `export_presets.cfg`.
WASM сжимается gzip без потери данных; встроенный загрузчик распаковывает его
в браузере. Все итоговые файлы проверяются на размер менее 25 000 000 байт.

Результат можно положить в корень репозитория GitHub и включить Pages из ветки
`main`, папки `/(root)`. Подробные инструкции создаются в итоговом `README.md`.
Никаких специальных заголовков сервера, SharedArrayBuffer или Git LFS не нужно.

`web_smoke.cjs` запускает проверку настоящего браузера через Chrome DevTools
Protocol (Node 22+). Нужны отдельный Chrome с `--remote-debugging-port=9449`
и HTTP-сервер сборки на порту 8915. Проверка сохраняет снимки загрузки, удержания
бомбы, её падения и взрыва, а также ошибки консоли и сетевые запросы.
